## 2026-08-27 记账不显示根因修复（二次排查）
- **根因**：`lib/features/ledger/ledger_providers.dart` 的 `expensesProvider` 在 `.map()` 内把 **portionsJson 当 JSON 数组**强制 `as List`（实际是对象 `{"id":2}`），`jsonDecode(...).as List<dynamic>` 抛 TypeError；该异常**未捕获 → 整条流进入 error → StreamProvider.value 变 null → 账单列表整体回退到「一笔都还没记」空状态**。即「记账成功却不显示」，且之前加的 `ref.invalidate` 无效（流已 error 无法自愈）。按份数模式必崩，且任一坏记录会拖垮整页。
- **修复**：
  1. 新增 `_tryMapExpense`（逐条 try，单条失败只丢该条，绝不拖垮整页）、`_decodePortions`（按对象解析）、`_safeExpenseType`/`_safeShareMode`（按名字安全兜底，避免 `.byName` 抛错）。`expensesProvider` 改用它们。
  2. `expense_edit_screen.dart` 的 `_save()` 新增激活团守卫：若 `activeGroupIdProvider.value` 为 null/空，拦截保存并提示「还没有激活的旅行团」，杜绝落到空 groupId 的「幽灵账单」（同样表现为记账成功却不显示）。
- 本环境无 SDK，未编译；需用户本地 `flutter analyze` 验证。
