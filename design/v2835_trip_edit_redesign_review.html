新建行程页重设计

✓
已选定方案 A · 预览驱动（2026-09-19 你确认）。下方 A 手机的布局即为施工依据，B / C 两案保留在此仅供对照，不再实施。
现状：trip_edit_screen.dart 是「6 张 SectionCard 等权竖排 + 尾部 PrimaryButton」， 在 390×844 屏上需要滚动约 1.9 屏才能碰到「创建行程」。方案 A 为纯前端重排， 不新增数据库列、不新增依赖、不触碰 schema 与同步链路，编辑模式（initialId != null）沿用同一套布局。

现状的五个问题

  • 无预览：选完封面、徽章、名称，却看不到行程卡最终长什么样——而这正是行程列表首页要展示的内容。
  • 主次不分：名称、目的地与「备注（选填）」是同一种白卡，视觉权重一样。
  • 动作在末尾：创建按钮排在 6 张卡之后，必须先滚到底。取消入口也没有（只能按返回键）。
  • 重复装饰：「行程徽章」和「封面渐变」都是外观，占了两张卡。
  • 日期无快捷：每次都要开抽屉、翻月、点两次、确认——4 步操作只为选「这周末」。

三套方案的取舍

方案形态操作步数
A推荐预览驱动单屏：顶部实时预览卡，下方紧凑设置最少
B三步引导：去哪儿 → 什么时候 → 长什么样+2 步
C极简单屏：一张主卡 + 折叠「更多设置」最少但要展开
推荐 A 的理由：它把「所见即所得」放在第一位——用户改封面、改徽章、改名字，顶部那张卡立刻跟着变，等于在创建时就能预览最终成果。B 的问题是与「编辑行程」共用时偏重（编辑只想改个日期却要过三步），C 的问题是折叠层藏了太多东西，第一次创建的用户容易漏掉封面与节奏。

任务 2

「时间线 / 攻略」贴紧底部胶囊栏

实测口径：底部胶囊栏 widget 自身高度 = Spacing.xs(4) + 66 + Spacing.sm(8) = 78（再加安全区 inset）。 而停靠条当前用的是全局 FAB 令牌 AppBottomLayout.actionButtonOffset = 80， 两者相差 2px；再叠加停靠条自身的描边与阴影，视觉上就是一条「悬空缝」。
现状：bottom = 80 + safe（差 78）→ 缝 2px + 描边阴影

攻略
2px 缝

停靠条浮在胶囊栏上方，两者之间有一道可见的暗缝，且停靠条自带的 outlineVariant 描边让它更像一块「贴在上面但没连上」的独立卡片。

方案：bottom = 78 + safe（与胶囊栏占位严格对齐）

停靠条底边与胶囊栏顶边严格接合：把停靠条下圆角改成 0、去掉下描边与外阴影，两者在视觉上拼成一个整体的「上方分段 + 下方导航」双段结构。

位置现在改为

任务 5 · 本轮新增

添加安排页重设计

现状：item_edit_screen.dart（601 行）是「8 张 SectionCard 竖排」—— 类型 / 名称+地址 / POI 搜索 / 安排日期 /（交通）出发地+到达地+航班号 / 开始时间+时长 / 费用 / 备注 / 保存按钮。 最长的交通类型要滚动约 2 屏。设计语言与新建行程页保持同族：聚焦录入 + 实时摘要 + 停靠保存。

现状的六个问题

  • 地址填两遍：一张卡是「地址」手填，下一张卡又是「搜索地点 (POI)」——两个入口干同一件事，用户不知道填哪个。
  • 时长步进反人类：MiniStepper 每按一次 ±15 分钟，想设 2 小时要点 8 次。
  • 时间信息散在三张卡：日期一张、开始时间一张、时长又在时间卡里，用户拼不出「我这条排在几点到几点」。
  • 类型占了整整一张卡：五个等宽格子横行，视觉重量压过了「名称」这个真正的主角。
  • 费用/备注各占一卡：一行就能装下的东西，各占一张 24 圆角白卡。
  • 保存按钮在滚动末尾：和新建行程页一样，必须先滚到底。

重设计的四条主线

主线做法
合并「地址」+「POI 搜索」合成一个「名称 → 自动建议 → 一键填地址」的流；日期/时间/时长合成一段「什么时候」。
摘要时间段顶部实时算出一行 09:00 → 10:30 · 共 1.5 小时，改哪个格子这行都跟着变。
点选时长改为 30分 / 1时 / 1.5时 / 2时 / 3时 / 自定义 六个 chip，常用值一次点按搞定。
停靠「保存安排」钉在底部；编辑模式左侧多一个「删除」。
没有引入任何新依赖：POI 建议复用的是页面里已有的 _onPoiChanged 防抖搜索与 _poiResults，只是把结果从「独立一张卡」挪到名称输入框正下方变成内联建议。地图选点本来就没实现（文件头注释里的「地图选点」是过期描述），本次一并清掉。

需要你确认的两点

① 时长快捷值取哪几档

我默认给的是 30分 / 1时 / 1.5时 / 2时 / 3时 / 自定义。如果你更常设半天或全天，可以换成 1时 / 2时 / 半天 / 全天 / 自定义。

② 是否要「复制上一段」

连续录多段交通时（厦门 → 鼓浪屿 → 回程），一键把上一条的到达地填成本条出发地。不加也不影响主流程，说一声即可。
