- 分支顺序改为：AI(`/ai`)、清单(`/checklist`)、行程(`/trips`)、账本(`/ledger`)、我的(`/profile`)；`HomeShell._tabs` 对应改为 🤖AI/📋清单/🧳行程/💰账本/👤我的。
- 移除原「消费」分支，把 `/expenses` 整个子树（edit/stats/settle/budget/categories）注册为**顶层 GoRoute**（全屏页，不带底部导航条），所有子路径不变——经查只有 `/expenses/*` 子路径被引用，跳转点零改动。
- 新增 AI 分支：`/ai`（聊天主页）+ 子路由 `/ai/settings`（AI设置页）。
- 开屏页 splash 已是 `context.go('/trips')`，在新顺序下自动落在中间「行程」tab，无需改动。

## 三、AI 助手（全新 feature，无新增依赖）

存储与配置（复用 map_config 现有模式）：
- `lib/data/repo/prefs_repo.dart`：新增 getAiConfig/setAiConfig，JSON 存 SharedPreferences key `ai_config`（baseUrl/apiKey/model）。
- `lib/data/providers.dart`：注册 aiChatServiceProvider 与 aiConfigProvider。

服务层（模仿 WeatherServiceImpl 的接口+impl+可选 Dio 注入模式）：
- `lib/data/services/ai_chat_service.dart` + `impl/ai_chat_service_impl.dart`：dio POST `{baseUrl}/chat/completions`，OpenAI 兼容格式，支持传入 tools、解析 tool_calls 返回；非流式（v1 不做打字机效果）。

工具系统（`lib/features/ai/ai_tools.dart`）：
- 工具 schema 白名单 + 执行器，全部只触碰本地 drift 数据库和偏好设置，**不提供任何联网浏览、通用 HTTP、文件读写或删除数据的工具**，满足"不能操作软件以外功能"的约束：
  - 查询类：查询账单（按日期/分类/成员/行程过滤）、成员余额榜、预算状态、结算状态、行程列表、某天日程、分类/成员列表；
  - 写入类：记一笔（add_expense，用姓名解析成员，走 saveExpense/ExpenseDraft）、创建行程（create_trip）、添加/修改行程安排项；
  - 设置类：切换主题、开关预算预警。
- System prompt 自动注入：当前日期、当前团 id 与成员名单(id)、分类 key、币种、行程列表摘要，让模型能把"小王"解析成 memberId；并写入作用域声明（只能使用提供的工具操作本应用）。
- 工具循环：最多迭代 8 轮防失控，工具执行结果作为 tool role 消息回传直至最终回答。

UI（`lib/features/ai/screens/`）：
- `ai_chat_screen.dart`：气泡式聊天界面 + 输入框 + 建议提示词胶囊（如"帮我记一笔午饭 45 元，我付的钱大家平摊""这个月谁还欠钱""帮我建一个成都 5 日游行程"）；发送时显示"思考中"，有工具调用时展示轻量过程 chip（如「已记账：午餐 ¥45」）；未配置 API 时显示引导卡片一键跳设置；会话内消息用 Riverpod StateProvider 保持。
- `ai_settings_screen.dart`：Base URL / API Key / 模型名三项输入 + 「测试连接」按钮（发一条最小请求验证连通性）+ 保存；风格仿 map_settings_screen。
- 入口：聊天页 AppBar 齿轮图标 + 「我的」页设置分组新增「AI 设置」条目（profile_screen.dart 加一行）。
