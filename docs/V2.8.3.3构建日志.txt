【本次构建的环境修正（重要）】
scripts/build_apk.ps1 无法通过本机 PowerShell 会话驱动（脚本第一步 flutter pub get
即中止且无输出，疑似会话输出管道异常）。改为在 Git Bash 中按脚本同等步骤手工执行，
结果等价。**踩坑**：Git Bash 下 POSIX 形式的 JAVA_HOME（/d/AI/env/jdk/...）会让
Gradle 报 "JAVA_HOME is set to an invalid directory"；必须用 Windows 形式
（D:/AI/env/jdk/jdk-17.0.2）。分析/测试两阶段不需要 Java，故该坑只在构建阶段暴露。
