## 五、S2 启动锁 / 开屏品牌化（B2）

规格（场景 K，第二批文档 §六）：

1. **开屏**：Logo 区换舟形；动线 = 光环扩散（沿用 scale 0.62→2.1）→ 舟身描边生长（CustomPainter stroke-dashoffset 等效：路径度量 900ms easeOutCubic）→ 双波纹扩散（1.4s 间隔 ×2）；主标题「芥舟」衬线（SerifTitle）+ 副标题 `CopyTokens.splashSubtitle` 不变；底色 `primary 4% → surface` 垂直渐变；总停留 1200ms 不变；
2. **锁屏**：键帽 76×60 → GlassSurface mini（blur16 + 高光圈 + 按压 scale 0.94 + selectionClick）；圆点阵 → 胶囊分段条（6 段 26×5，填充段 160ms easeOutBack 生长）；错误：整盘 translateX ±6 衰减抖动 320ms + error 触觉（沿用冷却/免责/文案）；
3. 波纹母题（两道弧线 opacity 16%）锁屏与开屏共享组件 `brand_waves.dart`；
4. `disableAnimations` 降级：跳过描边生长（直接显示）与抖动。

测试 ≥8：动线分段区间、PIN 全流程回归（错误/冷却/成功）、降级路径、波纹组件复用断言。
