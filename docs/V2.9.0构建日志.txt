修复清单（分域摘要）
-------------------------------------
【全局 / 锁】
 1) P0 启动锁深链绕过：AppLockGate.load() 移入 main()（runApp 前，2s 超时兜底）；
    redirect 在 ready==false 的隐含假设封死，/s/:token、/invite 冷启动不再绕锁。
 2) 锁拦截时记录 pendingLocation，解锁后回跳深链目的地（邀请码 / 分享口令不再丢）。
 3) 路由表新增 errorBuilder → 统一 404 兜底页（EmptyState + 回行程首页）。
 4) 夜航族 + 跟随系统时 isDark 恒真导致「跟随系统」静默失效 —— 已修。
 5) 窄窗拦截页区分「手机浏览器」与「桌面窄窗」文案；/lock 加入白名单；
    拦截页 emoji 图标换矢量。

【数据 / 安全硬伤】
 6) P0 清单 scope 失守（仓储层收口）：global 条目强制 tripId=null；
    deleteTrip / 备份导出 / copyFromTrip 的清单查询补 scope 过滤（删行程不再
    连带清光全局待办）；copyFromTrip 改 newId 生成主键 + 按 label 去重
    （二次复制不再撞唯一约束崩溃）；撤销删除回填 done 态。
 7) viewer 权限旁路收口（行程域）：增删天、备胎操作、相册增删照片、地图插交通
    全部补 canWrite 门控（入口隐藏 + 函数兜底双层）；viewer 拖拽改为拖不动。
 8) 编辑安排 sortOrder 硬编码 0 导致拖拽排序被重置 —— 透传原值。
 9) 结算历史「每行撤销都撤最近一轮」—— 撤销只渲染在新近一轮，L2 危险确认
    含影响账单数 + 成功 / 失败反馈。
10) 子预算 / 洞察胶囊把退款按 abs() 算成支出 —— 带符号累加，与统计口径一致。
11) 编辑行程缩短日期不裁剪安排（Day 0 / Day -1）—— 保存走 updateDates 夹取。
12) 装配台「换天建议」剩余容量恒错 —— 改传全行程记录计算占用。

【入口与导航】
13) 首页团卡「预算 N%」跳未注册路径 —— 改 pushNamed('budget')。

17) LAN 同步入口三处收敛（行程首页顶栏移除、团管理移除，留账本首页与分享中心）。
