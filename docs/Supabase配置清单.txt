芥舟 V2.6 · Supabase 配置清单（照做即可，约 10 分钟）
================================================================
目标读者：不熟悉 Supabase 的开发者/需求方本人。
语气约定：一步一步照做，不要跳步。本清单不含任何密钥值。

----------------------------------------------------------------
第一步：注册并新建项目
----------------------------------------------------------------
1. 打开 https://supabase.com ，注册/登录（可用 GitHub 账号）。
2. 点「New project」。名字随你起（比如 jiezhou），Region 挑离你最近的
   （Singapore / Tokyo 都行），数据库密码自己设一个并保存好。
3. 等待项目初始化完成（1~2 分钟）。

----------------------------------------------------------------
第二步：拿到两个值，填进应用
----------------------------------------------------------------
1. 进入项目后，点左侧最下面的 Project Settings（齿轮）→ API。
2. 你会看到两个值：
   * Project URL        形如 https://xxxx.supabase.co
   * anon / public key  一串很长的字符（新版本可能叫 Publishable key）
3. 填进应用，两种方式二选一：
   * 方式 A（推荐）：应用内「我的 → 云端与同步」页面，填入 URL 和 Key，
     点「保存并重连」。
   * 方式 B（打包时注入）：构建 APK 时加参数
     --dart-define=SUPABASE_URL=你的URL --dart-define=SUPABASE_ANON_KEY=你的Key

   **警告**：
   * anon key（Publishable key）是给客户端用的公开密钥，有 RLS 行级安全
     保护，可以放进应用；
   * service_role key（Secret key）绝对不能填进应用或告诉任何人！

----------------------------------------------------------------
第三步：执行建库 SQL
----------------------------------------------------------------
1. 左侧点 SQL Editor → New query。
2. 把仓库里 docs/db_v26.sql 的全部内容粘贴进去，点 Run。
3. 显示 Success 即完成（脚本可重复执行，重复跑也不会报错）。
   这一步创建了 10 张表、全部行级安全策略和 9 个云端函数。

----------------------------------------------------------------
第四步：核对登录设置
----------------------------------------------------------------
1. 左侧 Authentication → Sign In / Providers。
2. 确认 Email 登录是开启状态（默认就是开的）。
3. 建议：Authentication → Settings 里把「Confirm email」关掉，
   注册即可直接登录，体验更顺。

----------------------------------------------------------------
第五步：核对行级安全（RLS）
----------------------------------------------------------------
1. 左侧 Table Editor，逐个点开这 10 张表：
   trips_sync / trip_items_sync / groups_sync / members_sync /
   expenses_sync / settlements_sync / categories_sync /
   group_collab / share_links / app_settings
2. 每张表右上角确认 RLS 是绿色开启状态。如果哪张表显示未开启（红色），
   回到第三步重新跑一遍 db_v26.sql 即可。

----------------------------------------------------------------
换后端（自托管 / 国内镜像）
----------------------------------------------------------------
想换服务器：在应用里改「云端与同步」页的 URL/Key（或重新打包换注入值），
再在新服务器上跑一遍 db_v26.sql 即可，客户端逻辑完全不用动。

----------------------------------------------------------------
Troubleshooting（常见问题）
----------------------------------------------------------------
* 网页/应用提示「配置无效」：
  URL 是否以 https:// 开头？Key 是否复制完整（前后无空格）？
* 登录报错（403 / Invalid API key）：
  多半是 anon key 填错，或误填了 service_role key。回第二步重填。
* 同步中心一直显示「端点未配置」：
  ① 确认已做第二步；② 点同步中心「立即同步」；③ 看网络能否访问
  你的 Supabase 域名（浏览器直接打开 Project URL 应有响应）。
* 注册后没自动登录：
  第四步的 Confirm email 没关。关闭后重新注册或手动确认邮箱。
* 只读分享页打不开：
  确认分享链接格式 https://<官网域名>/#/s/<token>，且对方网站
  已部署最新 Web 版本。
